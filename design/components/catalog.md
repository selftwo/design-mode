# Designmode component catalog

Every class consumes semantic aliases from `tokens/tokens.css` only, so both themes work through the token seam alone. Wrap any surface in `.dm` to set ink, ground, and the UI face. Borders appear only on physical objects (islands, captured frames, dialogs, blooms, notices) and on graspable controls (buttons, inputs). Everything else separates by placement and value.

Each component belongs to one hue job: **violet** signals (selection, pressed, focus, dispatch), **coral** annotates, **teal** teaches, **green** marks runs, **neutral** is everything else.

| Component | Class | Hue job | Anatomy, variants, states | Use |
|---|---|---|---|---|
| Island | `.dm-island` | neutral | `.dm-island-head` (drag handle) with `.dm-island-title`, `.dm-grip`, `.dm-island-x`; `--summoned` + `[data-open]` for the settle entrance; `[data-dragging="true"]` kills transitions mid-drag | The floating chrome unit: white material, edge, lift. All tool chrome is islands over the field; nothing docks edge to edge. |
| Toolbar island | `.dm-island` + `.dm-toolbar` | neutral (violet on pressed tools) | `.dm-toolbar-title`, `.dm-toolbar-group`, `.dm-toolbar-spacer`; tools are `.dm-btn--quiet.dm-btn--sm[aria-pressed]`; wraps below 640px | Top chrome, once per screen: title, tool words (Select / Circle / Comment / Learn), Import, Live. |
| Status island | `.dm-island` + `.dm-status-island` | neutral | one mono line, tabular numerals | Bottom-corner chrome: counts, save state, live state as plain words. |
| Runs island | `.dm-island` + `.dm-sect` + `.dm-run-row` | green | row = `.dm-dot` + `.dm-mono` id + note; island present only while runs exist | Agent presence. Green is the only hue here; violet never marks a run. |
| Layers + aspects island | `.dm-island--summoned` + `.dm-sect`, `.dm-tree`, aspects sections | violet on selection | summoned on selection, opens on the side opposite the selected object; drag by header | The one inspector. Layers tree above, aspects below. |
| Layers tree row | `.dm-tree-row` with `.dm-tree-glyph`, `.dm-tree-meta`; `--frame`, `--mark`, `--stale`; `--lvl` sets indent | violet selection, coral mark glyphs | hover wash; `[aria-selected="true"]` signal wash + left keyline; selection syncs with the canvas | Board, frames, elements, marks as an indented hierarchy. |
| Aspects sections | `.dm-insp-sect` (`--first`), `.dm-arow`, `.dm-well` (`.dm-well-l`/`.dm-well-v`), `.dm-well-grid`, `.dm-align-picker` > `.dm-align-dot[data-active]`, `.dm-swatch-row` + `.dm-swatch`, `.dm-type-rows` > `.dm-type-row` | violet on active picker dots | stable section order: Layout, Flex, Radius, Fill, Border, Type; sentence-case headers; hairline between sections only; mono value wells | The Paper-inspector anatomy. Fill rows name the product's own tokens; the inspector speaks the reviewed product's CSS. |
| Button | `.dm-btn` | violet on `--primary` and `[aria-pressed="true"]` | `--primary`, `--quiet`, `--danger`, `--sm`; `:disabled` | All actions. Primary and toggled tools carry the signal; quiet is a wordlike action; danger reserves red for destructive intent. |
| Tab | `.dm-tabs` > `.dm-tab` | violet underline | `[aria-selected="true"]` | Panel mode switch. Active tab carries a 2px signal underline; no enclosure. |
| Input | `.dm-input`, `.dm-textarea`, `.dm-select`, `.dm-field-label` | violet focus ring | `:hover` edge, `:focus-visible` ring | Comment entry, rename fields, agent select, dispatch prompts. |
| List row | `.dm-list` > `.dm-row` with `.dm-row-title`, `.dm-row-support`, `.dm-row-meta` | violet selection | `:hover` wash; `[aria-selected="true"]` signal wash + left keyline | The lattice unit: title, one support line, mono meta on the right edge. Projects, captures, annotations. |
| Intent chip | `.dm-chip` | violet when pressed (coral inside a bloom) | `[aria-pressed="true"]`; inside `.dm-bloom` the pressed chip turns coral | A dispatchable intent attached to a mark (distill, bolder, adapt, …). Sunken fill at rest. |
| Badge as word | `.dm-badge` | state hues | `data-tone="ok\|warn\|danger\|info\|muted"` | State as a colored mono word. Never a boxed pill. |
| Status dot | `.dm-dot` | green running | `data-state="running\|done\|failed\|waiting"` | The smallest state signal. Running is the run green; it does not loop. |
| Agent activity row | `.dm-agent-row` with `.dm-dot`, `.dm-agent-title`, `.dm-agent-detail` | green dot | hover wash | One agent run in a list surface: dot, what it is doing, mono run id. |
| Comment | `.dm-comment` with `.dm-comment-head`, `.dm-comment-author`, `.dm-comment-time`, `.dm-comment-body` | neutral | | An annotation thread entry, capped at the comment measure. |
| Mark reference | `.dm-mark-ref` | coral | | Inline pointer to a canvas mark, set in the annotation ink over a coral wash. |
| Mark | `.dm-mark` base + `.dm-mark-circle` (`.dm-mark-num`), `.dm-mark-rect`, `.dm-mark-pin` | coral | `[aria-selected="true"]` focus ring; element rects carry a `.dm-scope-chip` | The reviewer's ink over captured pixels: circle mark with ordinal, element rect, numbered comment pin. |
| Scope chip | `.dm-scope-chip` (`--live`) | coral when live | dashed = stale or descriptive anchor; `--live` solid coral = the active mark | Names a mark's anchor (circle / element / pin) and its staleness. |
| Bloom | `.dm-bloom[data-open]` > `.dm-thread` with `.dm-thread-head`, `.dm-thread-state` (`--open`), `.dm-thread-c`, `.dm-avatar` (`--human`/`--agent`), `.dm-chip-candidate`, `.dm-prov`, `.dm-chip-row`, `.dm-thread-foot` (`--returned`) + `.dm-rdot[data-r]` | coral paper; violet agent avatar, candidate chip, returned foot | states as words: open (coral), draft, ✓ resolved; stale threads note "anchor is approximate"; scales from its mark with the one settle | The anchored comment thread. Grows out of its mark on coral paper: human comment + intent chips, agent candidate reply with ⌁ provenance line, routing foot. |
| Learn lens | `.dm-island` + `.dm-learn` with `.dm-learn-head` (drag handle), `.dm-learn-title`, `.dm-learn-sub`, `.dm-island-x`, `.dm-learn-empty`, `.dm-learn-body`, `.dm-learn-anatomy`, `.dm-learn-term`, `.dm-learn-why` | teal | `--summoned` + `[data-open]`; content updates in place as elements are clicked | The agent's second voice: floating teal island explaining the clicked element's anatomy and the word for what it is doing. Never actionable. |
| Teach note | `.dm-teach-note[data-open]` with `.dm-teach-chip`, `.dm-teach-stem` | teal | scales from its anchor; stem fades in at 0.6 | An explanation anchored on the canvas: teal paper, agent voice, no routing, no dispatch. |
| Notice | `.dm-notice` with `.dm-notice-action`, `.dm-notice-dismiss` | state hues | `data-tone="warn\|error\|success"` (default info) | The one notification shape. Tone changes color only, never geometry. Floats, so it keeps an edge and a lift. |
| Captured frame | `.dm-frame` with `.dm-frame-label` | violet selection ring | `[aria-selected="true"]` | A captured screen on the canvas. A true physical object: edge, lift, mono label. Its pixels keep their own palette. |
| Dialog | `.dm-scrim` > `.dm-dialog` with `.dm-dialog-title`, `.dm-dialog-body`, `.dm-dialog-actions` | violet primary action | | Modal confirmation. Enters with the one settle (`dm-settle`, 220ms, decelerating). |
| Status bar | `.dm-statusbar` with `.dm-statusbar-end`, `.dm-mono` | neutral | | Docked bottom chrome for full-shell layouts: frame id, zoom, save state as plain words. |
| Mono text | `.dm-mono` | neutral | | Ids, run names, frame names. The second and last type register. |
